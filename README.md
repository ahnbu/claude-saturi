# 클로드 사투리 사전 (Claude Saturi)

클로드(Claude)와 대화하며 매일 마주치는 특유의 번역투와 상투적 표현 24개를 모은 사전입니다.  
실제 업무 세션에서 추출한 생생한 문장과, 문맥에 맞게 다듬은 사람 말을 나란히 비교합니다.

- **웹사이트**: [https://ahnbu.github.io/claude-saturi](https://ahnbu.github.io/claude-saturi)
- **치트시트 (한눈에 보기 / PDF 저장)**: [https://ahnbu.github.io/claude-saturi/cheatsheet.html](https://ahnbu.github.io/claude-saturi/cheatsheet.html)

---

## 주요 특징

1. **실제 세션 기반 예문**: 지어낸 문장이 아니라 실제 작업 대화에서 클로드가 답변한 문장을 그대로 담았습니다.
2. **사람 말 전후 비교**: 어색한 번역투 문장을 문맥에 맞는 자연스러운 한국어로 바꾼 예시를 함께 보여줍니다.
3. **왜 이럴까? 촌평**: 클로드가 왜 이런 표현을 습관처럼 쓰는지 짚어보는 짤막한 풀이를 덧붙였습니다.
4. **인쇄용 치트시트**: 전체 24개 단어를 한눈에 보거나 A4 PDF로 내려받을 수 있는 치트시트 페이지를 제공합니다.
